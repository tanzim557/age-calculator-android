# Modern Age Calculator and AI Assistant (Android)

[![Kotlin](https://img.shields.io/badge/Kotlin-1.9+-7F52FF?style=for-the-badge&logo=kotlin&logoColor=white)](https://kotlinlang.org/)
[![Jetpack Compose](https://img.shields.io/badge/Jetpack_Compose-Material_3-4285F4?style=for-the-badge&logo=android&logoColor=white)](https://developer.android.com/jetpack/compose)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=for-the-badge)](https://opensource.org/licenses/MIT)

A modern, elegant, and production-ready Android utility application built using Kotlin and Jetpack Compose (Material 3). Features ultra-precise age calculations, next birthday countdowns, zodiac astrology breakdowns, and integrated AI assistant advisory.

---

## Key Features

- Exact Chronological Calculation: Computes years, months, days, total hours, minutes, and seconds lived.
- Birthday Countdown and Astrology: Calculates upcoming milestone birthdays, days remaining, and Western/Chinese zodiac insights.
- Integrated AI Assistant: Context-aware AI assistant answering date, age, and astrology queries.
- Material 3 Dynamic Theming: Full support for Dark Mode and Light Mode with fluid Compose animations.
- Clean Architecture: Strict adherence to MVVM (Model-View-ViewModel) with Kotlin Coroutines and StateFlow.

---

## Tech Stack and Dependencies

- Language: Kotlin
- UI Toolkit: Jetpack Compose (Material 3)
- Architecture: MVVM with Android ViewModel and StateFlow
- Build System: Gradle Kotlin DSL (build.gradle.kts)

---

## Building and Running

1. Clone repository:
   ```bash
   git clone https://github.com/tanzim557/age-calculator-android.git
   ```
2. Open project in Android Studio.
3. Let Gradle sync dependencies.
4. Select target emulator (API 26+) or physical device and click Run.
